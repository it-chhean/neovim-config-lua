It's just my own local setup for Java deveplopment enviroment.

Create neovim config folder
```bash
mkdir -p ~/.config/nvim
```

move into the directory
```bash
cd ~/.config/nvim
```

Create init.lua file
```bash
touch init.lua
```

Open the file
```bash
nvim init.lua
```

Paste my init.lua configuration into your `init.lua`:)
